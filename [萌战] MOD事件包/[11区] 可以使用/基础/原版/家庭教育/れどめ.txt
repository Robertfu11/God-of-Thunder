//	概要
//
//	子供の能力が微妙すぎてとても激動の宇宙を生き抜いていけない、育成コマンドなんて使わなくても
//	家庭で教育できるはずだ！という不満を和らげるユーザーイベントです。。
//	同じ勢力に任官中か平民のプレイヤーの子供がいる場合、毎月自動的に何かの能力が上がります。
//
//	※　学習内容を理解できずに能力が上がらない場合があります。
//	※　父の能力より子供の方が高かった場合、能力が上がらないことがあります。
//	※　基本の担当可能年齢である12歳以上の子供はこのイベントによる能力向上はできません。
//
////////////////////////////////////////////////////////////////////////////////////////////////////
