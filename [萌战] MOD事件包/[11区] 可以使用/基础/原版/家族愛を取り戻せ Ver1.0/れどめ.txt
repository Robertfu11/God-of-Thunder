//	家族が手下ではなく、どこかの覇王にいるんだけど略奪できない仕様に涙した方々へ。
//	妻＞娘＞姉妹＞息子＞兄弟＞両親の順に優先度が設定され、設定された家族の所属覇王の首都上空に
//	プレイヤー艦隊が存在する場合に家族が手下になる可能性があります。
//	対象となる家族は仕官、放浪、捕虜、平民のいずれかで、相手の忠誠が96以上だとお断りされます。
//	一度に設定できる家族は一人だけです。
//	今のところ設定された人物は非表示なのでウロウロして探してください。
//
//	現状のコマンドではこんな感じにしかできませんでした。
//	実行ブロックで惑星上の艦隊を取得できたりするとすべての家族を対象にできたりするんでしょうが
//	今やるならSMAX相当数のイベントファイルが必要に．．．。
//	もし現状でもこうすればいいんじゃない？ってアイデアがありましたら知恵をお借りしたいです。
