//	概要
//
//	PUK wikiの要望コメントを参考にして制作しました。
//	自勢力に諜報担当が存在する場合、どこの勢力でどんな女がいるか情報を得ることがあります。
//	派閥長以外でも低確率で自勢力に所属する女の弱みを得ることができるようになりました。
//	おまけで他勢力の諜報担当を捕虜にできます。
//	頻度はif_rnd等で調整して下さい。
//
////////////////////////////////////////////////////////////////////////////////////////////////////
//	注意
//
//	プレイヤーが覇王か派閥長の場合、有用性がないので弱みを得るイベントは起こりません。
//	このユーザーイベントはu600まで使用可能なv1.24以降を想定してあります。
//	このユーザーイベントによって生じたいかなる損害に責任を負いません。
