//	世論拡張イベント	by OLDman
////////////////////////////////////////////////////////////////////////////////////////////////////
//	概要
//
//	世論による効果を拡張します。
//	NPC覇王は資金が100000を下回ると強制的に反戦モードへ移行します。
//	おまけでプレイヤー覇王の信念は世論に影響を受けて変化します。
//	不要な方はupd_sts,poid_player,信念の行を削除してください。
//
//	反戦：	最大派閥長が武闘派の場合、好戦派による揺り戻しが活性化します。
//		信義派の派閥拡張の動きが活性化します。
//		民生品の供給率上昇により経済が活性化して民忠と資金が増加します。
//		増加する資金の額は人口に比例します。
//		技術研究予算が制限され技術値が低下する可能性があります。
//
//	中立：	武闘派、信義派が活発に拡張運動を行います。
//		内政のバランス化を図ります。
//
//	好戦：	最大派閥長が信義派の場合、反戦派による揺り戻しが活性化します。
//		武闘派の派閥拡張の動きが活性化します。
//		戦時体制により戦時出費がかさみます。
//		減少する資金の額は人口に比例します。
//		先端技術開発が奨励され技術知が上昇する可能性があります。
//		反戦デモが発生する可能性があります。
//
//	HOI3の政治システムを参考にしてみました。
//	プレイヤーに限れば平時は防衛力が下がり、資金獲得がしやすくなる反戦気運。
//	戦費を確保したら中立から好戦へシフトして戦争へ、という流れになるかなぁとおもいます。
//
