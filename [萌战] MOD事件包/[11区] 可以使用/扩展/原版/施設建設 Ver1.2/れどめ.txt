//	概要
//
//	プレイヤーが覇王か派閥長の場合、首都に施設を建設して様々な恩恵を受けます。
//	派閥長の場合には覇王の承認を得る必要があります。知力と交渉の値がカギです。
//	建設した施設は毎年2月にLvをあげることができます。
//	支配惑星数に応じてあげることのできる最大Lvが変化します。
//	首都星のみの場合はLv4までです。
//	施設紹介：
//	移民局		：ランダムで惑星の人口を上げます。Lvが上がると効果が上がります。Lv9では放浪
//			　中の人物が仕官する場合があります。
//	モニュメント	：ランダムで惑星の民忠をあげます。Lvが上がると効果が上がり、Lv9では部下の
//			　忠誠も微増します。
//	中央銀行	：資金を増やします。Lvが上がると効果が上がり、Lv9ではアイテムももらえます。
//	製薬工場	：薬品系アイテムがもらえます。Lvが上がると種類と個数が増えます。
//	秘密警察	：部下の忠誠が上がります。Lvが上がると効果が上がり、アイテムを入手することが
//			　あります。また、Lv9では他勢力の諜報担当を逮捕する可能性があります。
//	技術研究所	：ランダムで2種の開発値を上げます。Lvが上がると効果が上がり、Lv9ではアイテム
//			　がもらえます。
