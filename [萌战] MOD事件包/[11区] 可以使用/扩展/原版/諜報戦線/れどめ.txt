//	概要
//
//	PUK wikiの要望を元に特別外交を行うイベントを作成してみました。
//	プレイヤーが覇王か派閥長の場合、毎年２月に特別外交が行われます。
//	また、覇王の場合には基本コマンドに政略結婚と貢ぎ物が追加されます。
//
//	政略結婚：他勢力の覇王か王子に姫、妃、女王族のいずれかを嫁がせます。
//	貢ぎ物	：他勢力に資金提供して恨みを改善します。
//	派閥介入：他勢力の派閥の割合を増やします。
//	謀反	：他勢力の派閥長に独立をそそのかします。派閥介入にて支援している派閥の場合は若干、
//		　成功率が上がります。
//	流言	：他勢力にてデマを流して忠誠を低下させます。
//	暗殺	：他勢力の所属人物を暗殺します。
//
