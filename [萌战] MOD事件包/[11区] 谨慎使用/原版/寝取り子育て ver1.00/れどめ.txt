//	寝取り妻に子育てさせるイベント	by OLDman
////////////////////////////////////////////////////////////////////////////////////////////////////
//	概要
//
//	寝取って種仕込んでも出産時に淘汰されてしまうのはあんまりだ！！ということで制作。
//	プレイヤーが最大派閥長である場合に裏工作をして相手の夫をだまして出産、子育てさせます。
//	従来では発覚して修羅場ったり、夫が覇王だと追放されたりする処理に割り込みます。
//	プレイヤーの交渉が60か70なければ裏工作が失敗して規定のルートへ進みます。
//	覇王の妻の場合には産まれた子は王子か姫になります。
//
////////////////////////////////////////////////////////////////////////////////////////////////////
//	注意
//
//	子の父をプレイヤーのままにするので、本来親子のはずのイベントなどで呼び方がおかしくなる可能性
//	があります。
//	関連して相手の夫は自分の子だと思ってるのに子はプレイヤーを父として認識する歪な人間関係になり
//	ます。
//	このユーザーイベントは既存のp020aからp020e、5つのイベントを上書きします。
//	このユーザーイベントによって生じたいかなる損害に責任を負いません。
//	このユーザーイベントは非公式制作物であり、制作元であるMay(提督)とは一切関係がありません。
//	公式ではサポートされませんので制作元への問い合わせなどはご遠慮ください。
//
////////////////////////////////////////////////////////////////////////////////////////////////////
//	導入
//
//	1. PUKのインストールされた場所にあるeveフォルダを開き、p020で始まるtxtをバックアップします。
//	2. 解凍したp020a.txtからp020e.txt、5つのtxtをeveにコピーしてください。
//	
////////////////////////////////////////////////////////////////////////////////////////////////////
//	不具合、動作確認
//
//	雷神7+PUKのv1.26XGでサラッと確認しただけなので不具合が出る可能性があります。
